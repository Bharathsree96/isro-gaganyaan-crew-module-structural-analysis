# isro-gaganyaan-crew-module-structural-analysis
M.Tech thesis — hierarchical isogrid structural design for ISRO Gaganyaan crew module forward cone



# Structural Design of Crew Module (Forward Cone) 
# using Hierarchical Isogrid 🚀

## What is this project?
M.Tech thesis project contributing to ISRO's Gaganyaan 
human spaceflight program. Designed and validated a 
hierarchical isogrid structure for the conical forward 
section of the Gaganyaan crew module — optimising for 
buckling resistance while minimising weight.

---

## Problem it solves
The conical forward section of the Gaganyaan crew module 
needed a structure resistant to:
- Global buckling
- Skin buckling
- Rib crippling

While also minimising weight — a critical constraint 
in spacecraft design. Conventional isogrid structures 
were evaluated against a hierarchical isogrid design 
to determine the better performing option.

---

## Tools Used
| Tool | Purpose |
|---|---|
| MATLAB | Custom code to compute structural dimensional parameters |
| ABAQUS | Finite element analysis (FEA) and parameter optimisation |

---

## Key Results
- ✅ Hierarchical cone structure achieved a better 
  mass-to-buckling-load ratio than conventional isogrid
- ✅ Demonstrated enhanced buckling load capacity 
  under equivalent weight constraints
- ✅ Validated performance against global buckling, 
  skin buckling, and rib crippling failure modes
- ✅ Contributed to structural design knowledge for 
  India's first human spaceflight program

---

## Methodology
1. Reviewed conventional isogrid design limitations
2. Developed MATLAB code to compute hierarchical 
   isogrid dimensional parameters
3. Built finite element model in ABAQUS
4. Ran FEA simulations and optimised parameters 
   for weight reduction
5. Compared hierarchical vs conventional isogrid 
   performance under buckling loads
